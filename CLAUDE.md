# CLAUDE.md - Campuslands DevType

## Comandos Principales
- Desarrollo local: `npm run dev`
- Build de producción: `npm run build`
- Vista previa: `npm run preview`

## Estándares de Código
- TypeScript en modo estricto.
- Componentes funcionales en `src/components/` con tipado explícito de props.
- Persistencia local y datos en `src/data/`.
- Nuevos fragmentos de código deben clasificarse por lenguaje y nivel en `src/data/codeSnippets.ts`.
